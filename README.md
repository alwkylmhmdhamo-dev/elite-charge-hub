# 👑 Elite Charge Hub - متجر شحن رقمي احترافي

## 🎯 نبذة عن المشروع

**Elite Charge Hub** هو متجر شحن رقمي عصري وآمن بتصميم احترافي وفاخر.

### ✨ المميزات الرئيسية

- 🎨 واجهة فاخرة - تصميم أسود + ذهبي احترافي
- 📱 تطبيق ويب متجاوب - يعمل على جميع الأجهزة
- 🔒 أمان عالي الجودة - تشفير كامل
- ⚡ أداء سريع جداً
- 🌍 دعم عربي كامل
- 💳 طرق دفع محلية آمنة

## 🛠️ التكنولوجيا المستخدمة

- **Frontend**: React.js + TypeScript + Tailwind CSS
- **Backend**: Node.js + Express + MongoDB
- **Deployment**: Vercel + Heroku

## 🚀 البدء السريع

```bash
git clone https://github.com/alwkylmhmdhamo-dev/elite-charge-hub.git
cd elite-charge-hub
npm install
npm run dev
```
